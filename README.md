# Employee Management System
A terminal-based Employee Management System developed using Python and CSV file handling.

## Features
- Add Employee
- Display Employees
- Search Employee
- Remove Employee
- Update Salary
- Duplicate ID Validation
- Employee Count
- Colored Terminal UI

## Technologies Used
- Python
- CSV File Handling
- Tabulate
- Colorama

## Project Structure

Employee_Management_System
-main.py
-employees.csv
 -README.md

## How to Run

1. Open terminal
2. Run:

python main.py
